表格底部一条实时汇总：**框选一片是多少**（计数 / 求和 / 平均 / 极值），以及一共多少行、
筛掉之后剩多少、勾了几行。

它替代的是「导出到 Excel 里按一下自动求和」—— Excel 用户在任何表格控件里最先找的功能，
找不到就去导出。
