没有 CSS，不挂任何 DOM（除了在 `rootEl` 上设一个 `tabindex="-1"` 让键盘事件能冒泡上来）。

## 两层机制，因为核心只通知得了一半

| | 覆盖什么 | 谁负责 |
| --- | --- | --- |
| **自动层** | 列宽 / 列序 / 列显隐 / 排序 / 列头筛选 / 高级筛选 / 分页 | 插件。零配置 |
| **手动层** | 单元格编辑、行增删这类**数据**变更 | **使用方**在写回时调一次 `recordChange()` |

自动层能成立是因为这些状态全收在核心的 `getState()` 里：插件在 `onColumnsChanged` /
`onDataChanged` 时拿新快照与上一份比，变了就记一条，撤销就是把旧快照 `setState()` 回去。

手动层不得不存在是因为核心**没有任何编辑事件** —— `renderEditor` 返回的控件由使用方自己写回
行数据，核心根本不知道发生了什么。猜不出来的东西不猜（从 DOM 反推「刚才改了哪一格」是被禁止的
那类做法）。核心补上 `onCellEdit` 之后，手动层就能收成可选项。
