`virt-table` 走 **open-core**：核心（`@virt-table/*`，MIT）永久免费，少数进阶场景能力做成
**零侵入外部插件**，以 `@virt-table-pro/*` 独立发版、商业授权。

付费插件只吃核心公开的插件契约，不碰核心内部实现。所以它们装上就用、独立发版、
**不改核心一行代码**；不装的话核心照常完整可用。

授权模式与定价见 [企业版](/enterprise/)；许可怎么生效见
