装上就有：双击编辑（编辑态显示**原文**、关掉显示**结果**）、公式格左上角蓝色小三角、
点公式格把引用的格/区域用彩色虚线框标出来（Excel 的 range finder）、改一格沿依赖图只重算受影响的格。

## 数据模型：结果在格里，原文在 `_formulas` 里

```
输入：  { A: 1, B: 2, C: '=A1+B1' }
装载后：{ A: 1, B: 2, C: 3, _formulas: { C: '=A1+B1' } }
```

计算结果写回 `row[colKey]`，所以**显示、复制、导出、求和行全都零成本正确** —— 走的是核心的默认
取值路径，插件一行渲染代码都不用写。原文另存一份，编辑时显示它，`JSON.stringify` 保存草稿也带得上。

字段名可改：`vtFormula({ formulaField: '$fx' })`。

## 行号 = 数据下标 + 1，所以别开排序 / 筛选

A1 记法要求行号**绝对**，而表格的行序是**视图**。两者不可能同时成立，这里选了前者 ——
否则从 Excel 粘过来的公式全部失效，而那正是这个能力的卖点（与 Handsontable 的选择一致）。

装载时若检测到排序 / 筛选 / 高级筛选 / 分页 / 分组 / 树形列，会 `console.warn` 说明公式会指到
别的行上。**只警告不阻止** —— 「先按某列排一下再看」的临时操作偶尔是有意的。

## 配置项

| 选项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `columns` | `string[]` | 全部**非功能列**的叶子列 | 参与公式的列，**顺序即 A、B、C…**。显式给一份，以后在最左边插列不会让字母集体错位 |
| `formulaField` | `string` | `'_formulas'` | 公式原文存在行数据的哪个字段上 |
| `functions` | `Record<string, FormulaFunction>` | — | 自定义函数 |
| `maxRangeCells` | `number` | `100000` | 单个区域上限。超了那条公式标 `#VALUE!` 而不是硬算 |
| `markCells` | `boolean` | `true` | 给公式格的 `<td>` 打 class + `title`（原文） |
| `editor` | `boolean` | `true` | 自动给参与列装公式编辑器。列上已有 `renderEditor` 时不覆盖 |
| `highlightRefs` | `boolean` | `true` | 点/编辑公式格时框出它引用的格与区域 |
| `onActiveCellChange` | `(ref: string \| null) => void` | — | 当前格变化（点击表体）。做公式栏用这个 |
| `onRecalculated` | `(info: { changed, errors }) => void` | — | 每轮重算之后 |

::: tip onActiveCellChange 为什么存在
装了 `vtCellSelection` 之后核心的 `getActiveCell()` 一直是 `null`（两者共用同一份「当前单元格」），
想做 Excel 那样的公式栏就没有可靠的「当前格」来源。这个回调补上它。
:::

## 实例 API

| 方法 | 返回 | 说明 |
| --- | --- | --- |
| `getCellFormula(ref)` | `string \| null` | 某格的原文；不是公式格返回 null |
| `setCellFormula(ref, input)` | `boolean` | 写一格：`=` 开头当公式，否则当字面值。越界返回 false。立刻增量重算并重画 |
| `getCellValue(ref)` | `unknown` | 当前值（公式格是结果，字面格是输入） |
| `fillFormula(fromRef, toRef)` | `number` | 把公式按偏移填到目标格/区域，返回填了多少格 |
| `recalculate()` | `number` | 全量重算（改了源数据或换了一批数据之后） |
| `getSheetErrors()` | `Array<{ id, code, detail }>` | 所有出错的格，如 `{ id: 'C3', code: '#DIV/0!' }` |
| `getCellDependents(ref)` | `string[]` | 谁**直接**引用了这一格（追踪引用 UI 用） |
| `getCellReferences(ref)` | `Array<{ text, rect }>` | 这一格引用了哪些格/区域（区域保持整体，`rect` 是 0 基坐标） |
| `highlightCellReferences(ref)` | `number` | 手动高亮（传 `null` 清除）。点击时会自动调它 |

### 公式栏（Excel 的 fx 栏）

```ts
let currentRef: string | null = null;

vtFormula({
  onActiveCellChange: (ref) => {
    currentRef = ref;
    refLabel.textContent = ref ?? '—';
    // 公式格显示原文，字面格显示值 —— 与编辑态里看到的东西一致
    fx.value = (ref && table.getCellFormula(ref)) ?? (ref ? String(table.getCellValue(ref) ?? '') : '');
  },
});

fx.addEventListener('keydown', (e) => {
  if (e.key === 'Enter' && currentRef) table.setCellFormula(currentRef, fx.value);
});
```

### 填充柄

```ts
table.fillFormula('D2', 'D3:D100');
// 相对引用跟着偏移（D2→D3），$E$2 这样锁住的不动
```

### 绝对引用

`$` 锁住的部分在填充/偏移时不动，与 Excel 一致：`=D2*$E$2`、`=$A1`、`=A$1`。
