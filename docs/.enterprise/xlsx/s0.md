导出**真 xlsx**（zip + OOXML），以及给 PDF / 打印排好版。

核心自带的 `exportExcel()` 是 **HTML 伪装的 `.xls`**：Excel 能打开，但列宽、合并、冻结、
数字与日期的真类型、多 sheet 全都没有，新版 Excel 打开时还会先弹一句「文件格式与扩展名
不一致」。分层就落在这条线上 —— 免费版够用不精致，本包出真格式。

| | 核心 `exportExcel()` | `exportXlsx()` |
| --- | --- | --- |
| 容器 | HTML 文本改名 `.xls` | zip + OOXML |
| 表头 | 一行 | **多级分组表头**（含表头合并） |
| 合并单元格 | 无 | 静态 `merges` 与列 `mergeKey` 的自动合并都还原 |
| 列宽 / 对齐 | 无 | 跟随列配置 |
| 数字 / 日期 | 全是文本 | 数字是数字、日期是日期（收到的人能再排序、能参与公式） |
| 冻结窗格 | 无 | 有 |
| 多 sheet | 无 | 有 |
| 合计行 | 无 | 有，还能写成活 `SUBTOTAL` 公式 |
| 打印 | 新窗口 + 一份内联样式 | 分页、**每页重复表头**、页码、横向、缩放到一页宽 |

**不引 SheetJS / exceljs。** zip 写入器自带一份（约 150 行），DEFLATE 走浏览器原生的
`CompressionStream('deflate-raw')`，环境不支持就自动落不压缩（文件大一点，但完全合法）。
整个包 gzip 后约 11 kB —— jszip 单独一个就 95 kB，而它们会进你的 bundle。

本包**没有 CSS**，所以也不需要引样式。
