一格里一条趋势线。四种图型：折线、面积、柱状、盈亏。

不引图表库 —— 生成的是一段**静态 SVG 字符串**，没有实例也没有生命周期。

```
┌──────────┬───────────────────┬──────────────┐
│ 产品     │ 12 周趋势          │ 近 10 日盈亏 │
├──────────┼───────────────────┼──────────────┤
│ A        │    ╭─╮    ╭──╮    │ ▍▍ ▍▍▍  ▍   │
│          │ ╭──╯ ╰────╯  ╰●   │   ▔  ▔  ▔▔  │
├──────────┼───────────────────┼──────────────┤
│ B        │ ●╮      ╭────╮    │ ▍▍▍▍▍▍▍▍▍▍   │
│          │  ╰──────╯    ╰●   │              │
└──────────┴───────────────────┴──────────────┘
     type: 'line', markers: ['first','last']   type: 'winloss'
```

行上存一个数组，列上说一句「这一列画折线」，就完了：

```ts no-check
// 行数据
{ id: 1, name: 'A', weekly: [12, 18, 15, 22, 30, 28], pnl: [1, 1, -1, 1, -1] }
```
