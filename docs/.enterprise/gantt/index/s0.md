把甘特拆成**两个横向滚动视口**：左边是使用方那张 virt-table（只装业务列），
右边是插件自己的时间轴 pane（表头、网格、条都由插件画）。**行永远只由左表拥有** ——
条的纵坐标取核心的 `getRenderedRowRects()` 再换算到 pane 的内容坐标，
所以行对齐是构造上就对的，不需要「两个表格互相同步纵向滚动」那套。

| | |
| --- | --- |
| **左右各自横滚** | 任务列多到超出面板宽度时面板自己滚，时间轴不动；反之亦然。面板宽度由 `panelWidth` 定，也能一键收起 |
| **纵向只有一份真相** | pane 里一行 DOM 都没有，不存在双行池、也不会有分组行 42px vs 40px 的逐行错位 |
| **横向滚动** | **零 JS** —— 表头与条都在 pane 的内容坐标里，由合成器平移，插件不注册横向滚动回调 |
| **纵向滚动** | 1.35 ms/帧（5000 行实测，条与箭头全量重算）；在 pane 上滚滚轮由 JS 桥接给左表 |

行列虚拟化、树形 WBS、单元格编辑、键盘导航、导出仍然全部落在左表那侧 —— 那是一张**没有任何特殊配置**的
virt-table（插件只做一件事：把业务列上的 `fixed` 摘掉，否则冻结列不参与滚动，面板自己的横滚就废了）。

## 界面上每个元素是什么

这一节回答「看到的这个东西是什么、怎么关」。

| 看到的 | 是什么 | 由什么产生 | 怎么关 / 怎么改 |
| --- | --- | --- | --- |
| **浅色条** | 一个任务的工期 | 行的 `start` / `end` | 颜色：`barColor`（按某列取值）/ `barClass` / `--vtp-gantt-bar-bg` |
| 条内**实色的左段** | 完成进度 | `progress`（`0..1`，给 `0..100` 也认） | 不配 `progress` 就整条一色；颜色 `--vtp-gantt-bar-progress-bg` |
| 条内文字是**黑或白** | 取所压那块底色的反色（WCAG 亮度定），见<ProLink to="gantt/internals#条内文字的颜色">「条内文字的颜色」</ProLink> | 自动 | 想固定就自己覆盖 `--vtp-gantt-bar-text` |
| **灰色细条 + 两端下垂角** | **汇总条**：跨越全部后代时间范围的只读细条。**默认只有分组行有** | 见<ProLink to="gantt/data#层级怎么做-分组-还是-树形">「层级怎么做」</ProLink> | `summaryBars: 'group' \| 'container' \| false`；颜色 `--vtp-gantt-summary-bg` |

| **浅灰竖向底纹** | 非工作日（默认周六周日） | 仅日视图 | `showNonWorking: false` / 自定义 `isNonWorking` |
| **斜线底纹** | 这几天**不计入工期**（`workdaysOnly` 下的周末、`skipHolidays` 下的法定节假日）—— 条上那个「n 天」跳过了它们 | 面板上的「仅计算工作日」/「跳过法定节假日」 | 默认关；颜色 `--vtp-gantt-excluded-color` |
| 条内右端的**「n 天」** | 工期。跳过哪几天看上面那两个开关 | 默认渲染 | `showDuration: false`；单位 `texts.dayUnit` |
| 表头某个日期**变了颜色**、hover 有名字 | 那天是 `holidays` 里的法定节假日（**一直标**，与算不算工期无关） | `holidays` | 颜色 `--vtp-gantt-holiday-color` |
| **紫色竖线 + 日期格底部的小旗子** | **里程碑**：贯穿所有行的节点（发布日、评审会）。**名字要 hover 才显示** | `markers` / 表头点出来 | `setGanttMarkers([])`；颜色 `--vtp-gantt-marker-color` |
| 竖向分隔线 | 分组（月/年）边界 | 默认只在分组边界画 | `gridLines: 'group' \| 'bucket' \| 'none'` |
| 时间轴那侧**没有**行横线，左侧任务列**有** | 时间轴那侧没有单元格（它不是表格），横线只会穿过一片空白 | — | — |
| 短条的文字跑到了条**外面** | 条内放不下时自动外移，而不是截断成「需求与…」 | `barLabel` | `barLabelPlacement`，见下 |
| 最上面那条**工具栏** | 左边四颗改「表格看什么」：**字段配置**（列显隐 + 拖拽换序）、**筛选**（核心的 AND/OR 条件树）、**分组**（多级分组维度）、**排序**；有生效内容时点亮 + 数字徽标 | `toolbar: true` | 默认关；四颗可分别关掉，见<ProLink to="gantt/options#顶部工具栏">配置项</ProLink> |
| 工具栏右侧的**「甘特图配置」按钮** | 点开是个面板：开始 / 结束日期、标题展示、颜色显示、进度显示、仅计算工作日。控件全部来自核心（`createPopup` / `createSelectField` / `createSwitch`） | `toolbar: true` | 默认关；可按行开关，见<ProLink to="gantt/options#gantt-config">配置项</ProLink> |

| 某一行**完全没有条** | 那一行没有完整日期（未排期） | — | `editable.create` 后 hover 出 `+`，点一下就能排 |
| 拖行时出现的**一条横向蓝线** | 拖拽换序的落点，跨「任务列 + 整条时间轴」 | `editable.reorder` | 默认关；颜色 `--vtp-gantt-drop-color` |
| 右下角「未授权」角标 | 许可未设置 | `@virt-table-pro/license` | `setLicenseKey(key)` |
