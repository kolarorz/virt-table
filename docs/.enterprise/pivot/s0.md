行列维度分组聚合 + 交叉分析：把明细行换成一张「行维度 × 列维度」的交叉表，
带小计与总计。

## 它其实是「一棵树 + 一套分组表头」

这是整个设计，也是它体量不大的原因：

- **行维度**产出带 `children` 的树，行维度列配 `type: 'tree'`
- **列维度**产出列的 `children`（多级分组表头）

于是折叠展开、缩进、折叠箭头、`toggleFold()` / `expandAll()`、跨列的表头格、跨渲染窗口
边界的表头裁剪、固定列阴影 —— **全都是核心已经有的**，这个插件一行都没写。

```
rows: ['region','dept']   columns: ['quarter']   values: [金额/sum, 笔数/count]

┌────────────┬──────────────────┬──────────────────┬──────────────────┐
│            │        Q1        │        Q2        │       总计       │  ← 列维度
│ region/dept├────────┬─────────┼────────┬─────────┼────────┬─────────┤
│            │  金额  │  笔数   │  金额  │  笔数   │  金额  │  笔数   │  ← 值字段
├────────────┼────────┼─────────┼────────┼─────────┼────────┼─────────┤
│ ▸ 华东  ³  │    400 │       2 │    200 │       1 │    600 │       3 │  ← 小计行
│ ▸ 华南  ¹  │    400 │       1 │        │         │    400 │       1 │
│   总计     │    800 │       3 │    200 │       1 │  1 000 │       4 │
└────────────┴────────┴─────────┴────────┴─────────┴────────┴─────────┘
```
