# React 国际化 i18n

表格所有内置 UI 文案（空数据、加载、合计行、表头排序提示、列头筛选下拉、全文搜索框、高级筛选算子与构建器）收纳进统一的 `locale` 字典。内置 `zhCN`（默认）与 `enUS` 两个完整语言包，`@virt-table/react` 直接透传。

## 说明

- 构造时用 `locale` 选项覆盖：接受 `DeepPartial<VirtTableLocale>`，与 `zhCN` **深合并**，只写想改的项即可。
- 运行时用 ref 上的 `setLocale(locale)` 动态切换语言。
- 既有单项选项 `emptyText` / `loadingText` / `summaryText` 优先级**高于** `locale`（向后兼容）。

## 相关 API

| 字段 / 方法 | 作用 | 详见 |
| --- | --- | --- |
| `locale` | 覆盖内置文案，与 `zhCN` 深合并 | [表格配置 · i18n](/vanilla/api/table#国际化-i18n) |
| `setLocale` / `getLocale` | 运行时切换 / 读取当前语言包 | [实例方法](/vanilla/api/instance) |
| `zhCN` / `enUS` / `mergeLocale` | 内置语言包与深合并工具 | [表格配置 · i18n](/vanilla/api/table#国际化-i18n) |
| `emptyText` / `loadingText` / `summaryText` | 单项选项，**优先级高于** `locale` | [表格配置](/vanilla/api/table#virttableoptions) |

单元格组件是纯工厂函数、拿不到表格实例，所以日历面板的文案**不跟随** `setLocale()` —— 在列上传 `texts`，见 [VtDateRangePicker](/react/examples/cell/vt-date-range-picker#文案与-i18n)。

> 上面的字段在 React 端原样透传（实例方法通过组件 `ref` 调用）。封装层特有的部分 —— 组件 Props、渲染函数返回 JSX、`ref` 转发了哪些方法 —— 见 [React API](/react/api/table)。
